How it works

Three steps. No proxy. No key juggling.

1

Install the SDK

Drop in one package. Validate your license key once on init — that’s the only call that ever reaches our servers.

2

Pick a bundle

Choose the bundle for your job-to-be-done — MEV, CEX market data, SEC filings, macro stats. Every endpoint is typed and normalized.

3

Calls go direct from your machine

Data requests go straight from your machine to the platforms’ public endpoints. Rate limits stay per-user, exactly as if you went direct — we never see your data.

Developer experience

Typed. Cached. Freshness-enforced.

Every result carries its source, fetch time, and a freshness label. Ask for a max age — if no result is fresh enough, the SDK tells you instead of silently returning stale data.

import { UnifiedData } from "@unified-data/sdk";

const sdk = new UnifiedData({ licenseKey: process.env.UNIFIED_DATA_KEY });

// Quote BTC/USDT, refusing anything older than 60 seconds
const quote = await sdk.crypto.cex.quote("BTCUSDT", { maxAge: 60 });

console.log(quote.price);      // 97,412.55
console.log(quote.source);     // "binance"
console.log(quote.freshness);  // "LIVE" — fetched on demand, seconds old

Ask for a maxAge and the SDK throws StaleData (with the last fetch time) rather than handing you an old number. Freshness labels are on by default — hiding one is an explicit opt-out.

Freshness promise

Minutes, not days

Every result is labeled. A price is never presented as live when it is cached — we treat that as a defect, not a feature.

LIVE

Fetched on demand from the upstream in this call — or pushed over an active stream within the last few seconds.

CACHED

Served from the SDK cache. The exact age travels with the result, so you always know how old it is.

ESTIMATE

A derived or indicative value — never a firm quote. Never displayed as a price without the label attached.

Price bundles default to a 2-minute max age: live quotes are fetched on demand and never silently served older than 120 seconds unless you explicitly allow caching.

Privacy

The heartbeat is counts only

Metering works through a lightweight license-key validation plus a usage heartbeat to our server. It is the only traffic that touches our infrastructure, and it carries counts only:

  • Aggregated call counts per bundle — e.g. "crypto.cex": 842
  • SDK version and platform

Never sent: query parameters, symbols searched, addresses looked up, locations, or any user data. The heavy data never touches our servers — that’s the trust contract.
